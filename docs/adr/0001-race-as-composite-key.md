# レースを独立エンティティにせず、Memo が開催日・競馬場・レース番号を持つ

平場（条件戦）にはレース名がなく、レースを同定する情報は開催日・競馬場・レース番号の3つ組で足りる。そこで turf-notes は races テーブルを作らず、Memo にこの3項目（＋任意のレース名）を持たせる。同じ3つ組を持つ Memo は同じレースについてのメモとして扱い、「レースページ」はその3つ組でメモを束ねた表示として成立させる。

## Considered Options

- **レースを独立テーブルにする**: レースを1回作れば複数の Memo がぶら下がり、レース単位の属性（結果など）を後から足せる。しかし「レースを作る → メモを書く」の2段階になり、書く摩擦が増える。このアプリでは書く摩擦の低さが最優先。
- **レース名をタグにする**: 平場に名前がないため成立しない。重賞でも同名が年ごとに繰り返り、別レースが同じタグに混ざる。
- **3つ組をタグの合成で表す**: `東京` + `11R` のようなタグの組み合わせでは、別の日の同じ番号のレースと区別できない。
